/n**Step 1: the resource**
/nThis API manages books. Each book has the following fields:

| Field | Type | Description |
|---|---|---|
| title | string | The title of the book |
| author | string | The author of the book |
| genre | string | The genre, such as fiction |
| pages | integer | The number of pages |

The numeric field is `pages`. The filterable fields are `genre` and `author`.
